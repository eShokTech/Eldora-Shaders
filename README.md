# ELDORA Shaders

Original RenderDragon shader project for Minecraft Bedrock Android.

## Target

- Minecraft Bedrock 1.26.60.x
- Android / RenderDragon
- Primary device for validation: Samsung Galaxy A26 5G (SM-A266M)
- Performance-first profile

## Visual direction

A restrained medieval-fantasy atmosphere: readable daylight, warm gradual golden hours, deep blue but playable nights, warm artificial light, biome-aware fog, and stronger rain fog.

## Project rules

1. All shader source authored for ELDORA. No copying or adapting third-party shader source.
2. Third-party projects may be consulted only for public technical documentation, file formats, build tooling, and compatibility research.
3. Never publish a pack as a working shader until it has been compiled and validated in Minecraft.
4. Keep experimental builds separate from the main ELDORA world.
5. Prefer low-cost effects and stable frame pacing over expensive visual effects.

## Status

Repository bootstrap. The shader source and verified Android .mcpack have not been produced yet.
